## ✨ Features

- 🛍️ Digital Store
- 💙 Tema Biru Putih
- 🌙 Dark Mode (Biru Hitam)
- 👤 Login Admin
- 🔐 JWT Authentication
- 🔒 Password Hash (bcrypt)
- 📦 CRUD Produk
- 📋 CRUD Order
- 📱 Multi WhatsApp Admin
- 📊 Dashboard Admin
- 💬 Checkout ke WhatsApp
- 🍃 MongoDB Database
- ⚡ Next.js 15 App Router
- 📱 Responsive Mobile
- 🚀 Deploy Ready (Vercel)

# ⚙️ Install

```bash
git clone https://github.com/reyclouddev-ops/myshop.git

cd myshop

npm install

npm run dev
```

---

# 🔑 Environment

Buat file `.env.local`

```env
MONGODB_URI=

JWT_SECRET=
```
