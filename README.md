# 🚀 Instalasi

Clone repository

```bash
git clone https://github.com/reyclouddev-ops/myshop.git
```

Masuk ke folder

```bash
cd myshop
```

Install dependency

```bash
npm install
```

Jalankan project

```bash
npm run dev
```

Website berjalan di

```text
http://localhost:3000
```

---

# 🔑 Environment Variable

Buat file `.env.local`

```env
MONGODB_URI=

JWT_SECRET=
```
